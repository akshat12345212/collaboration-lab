# Collaboration Lab

A small public repository for practicing healthy GitHub collaboration: focused changes, clear pull requests, co-authored work, and explicit reviews.

## Principles

- Keep each pull request focused and understandable.
- Credit everyone who genuinely contributes.
- Request review when another perspective improves the change.
- Prefer useful documentation and reproducible examples over placeholder commits.

## Exercises
