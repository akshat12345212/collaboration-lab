# Co-authored workflow

This note records the collaboration workflow shared by **Akshat X Gupta** (`@akshat12345212`) and **Akshat Gupta** (`@akshat-gupta001`).

## Working agreement

1. Start with a small, clearly named branch.
2. Explain the purpose and user impact in the pull request.
3. Credit every contributor through GitHub-supported authorship metadata.
4. Keep review comments specific, respectful, and actionable.
5. Merge only when the resulting history tells the truth about the work.

## Definition of done

- The change is focused and readable.
- The relevant file checks pass.
- Contributors are attributed correctly.
- The pull-request summary matches the final diff.
